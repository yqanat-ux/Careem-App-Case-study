# Careem App: UX & Systems Case Study

A comprehensive analysis of the Careem mobile application, focusing on user experience, system workflows, and feature viability in the Saudi Arabian market.

**Author:** Yasser Qanat

## 🎯 Project Objective
The goal of this study was to analyze the current system architecture and user flow of the Careem application. I aimed to identify pain points in the booking process and propose data-driven improvements to increase user retention and operational efficiency.

## 🔍 Methodology
To conduct this study, I utilized the following analytical frameworks:
* **UX Audit:** Heuristic evaluation of the core booking interface.
* **User Flow Mapping:** Visualizing the steps from app launch to ride completion.
* **Competitive Analysis:** Comparing core features against regional alternatives (e.g., Uber, Bolt).
* **SWOT Analysis:** Assessing the strengths, weaknesses, opportunities, and threats for the platform's service ecosystem.
